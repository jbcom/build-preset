Release Please maintains the canonical
[CHANGELOG.md](https://github.com/jbcom/build-preset/blob/main/CHANGELOG.md), version metadata,
tags, and GitHub Releases. Published releases use npm provenance and the project supports the latest
`0.x` line.

For planned changes, use a Conventional Commit type such as `fix:`, `feat:`, `docs:`, `refactor:`,
`test:`, or `chore:`. Breaking public API changes need a `!` or `BREAKING CHANGE:` footer.
